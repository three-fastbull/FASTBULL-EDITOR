# Editing modes

| Mode | Viewer promise | Pacing | Suggested structure |
|---|---|---|---|
| `vlog` | Experience and personality | Natural; preserve breaths | Event, journey, lesson, follow |
| `value` | A useful takeaway quickly | Tight | Problem, answer, example, action |
| `awareness` | Remember a new idea or brand | Clear and cinematic | Old belief, new view, brand meaning, recall |
| `sales` | Decide whether to act | Fast and explicit | Problem, result, proof, offer, CTA |

Use `lib/fastbull_modes.py` as the executable source of truth for thresholds, caption density, insert intervals, and default CTAs. A mode changes editorial decisions; it is not merely a color preset.
