# FASTBULL visual system

- Direction: SPORT LUXURY PERFORMANCE.
- Core colors: deep navy `#071426`, gold `#D7B56D`, warm ivory `#FFF8EA`.
- Thai type: bundled Noto Sans Thai Variable (OFL); keep headlines bold and short.
- Captions stay inside the vertical platform safe zone and use gold only for the active word.
- Use a strong opening headline, restrained transitions, original local SFX, and one clear CTA near the close.
- Prefer clean composition and purposeful inserts over decorative effects. Preserve face visibility and speech comprehension.

The implementation lives in `remotion-composer/src/FastbullTalkingHead.tsx`. Avoid fetching web fonts during render.
